# Тематический бейзлайн

Запуск из корня проекта.

```bash
python -X utf8 -m evaluation
```

`recommend_by_topic` использует общий контракт `Recommender`. Он ищет темы каталога как целые слова или фразы в тексте задачи. Перед сравнением нормализует регистр, разбивает текст по пунктуации и заменяет «ё» на «е». Материалы с большим числом совпавших тем идут первыми, при равенстве сохраняется порядок каталога. Пустая задача и запрос без совпадений дают пустую выдачу. Стадия, сфера, опыт и история предназначены для проверки персонализированного алгоритма.

`profiles.demo.json` содержит десять вручную размеченных сценариев для `fixtures/catalog.demo.json`. В каждом сценарии `profile` задаёт вход, `relevant_ids` перечисляет подходящие материалы, а `note` объясняет разметку. Поле `history_fixture` подключает журнал из `fixtures/`. Две пары сценариев позволяют проверить эффект стадии бизнеса и журнала при одинаковой задаче.

Hit@3 — доля сценариев, где в первых трёх рекомендациях появился хотя бы один материал из `relevant_ids`. Сценарий вне каталога с пустым списком показывается отдельно. Для пар дополнительно сравнивайте первый результат, поскольку Hit@3 учитывает сам факт попадания.
